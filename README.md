# Interface de Controle de Tanques à Distância 🎛️💧

Uma iniciativa do **IEEE CSS UnB** desenvolvida no **Laboratório de Controle de Processos Industriais (LCPI)**, localizado no Prédio SG-11 da Universidade de Brasília.

Este projeto foca no replanejamento, adaptação física e automação de plantas didáticas de controle de fluidos em tanques, permitindo que estudantes de todo o mundo realizem estudos práticos de controle de forma totalmente **remota**.

---

## 📌 Visão Geral do Projeto

As bancadas didáticas de controle de fluidos passaram por um processo de manutenção e recuperação profunda. Com a integração desta interface de controle remoto, o retorno prático dado à universidade ganha escala internacional, viabilizando o acesso ao laboratório de maneira digital e dinâmica.

O projeto é orientado diretamente pelo **Professor José Oniram** e encabeçado pelo capítulo estudantil **IEEE CSS UnB**.

---

## 🖥️ A Interface de Controle

A imagem abaixo exemplifica o ecossistema digital desenvolvido para o monitoramento das bancadas:

*   **Sinótico do Processo:** Visualização em tempo real dos níveis de fluidos (Tanque 1 e Tanque 2), status das bombas e fluxômetros (ex: vazão em L/min).
*   **Modo de Operação:** Seleção rápida entre controle Manual, Automático ou Remoto.
*   **Painel de Operação Físico/Virtual:** Controles simulados de Emergência, Liga/Desliga, Reset e gráficos integrados de curvas de resposta.
*   **Alertas e Eventos:** Histórico em tempo real de avisos críticos do sistema (ex: Nível crítico atingido, falha de conexão).

---

## 🛠️ Tecnologias e Estrutura Previstas

*   **Automação Industrial:** Integração com CLPs, sensores de nível industriais e atuadores (bombas/válvulas).
*   **Backend & Conectividade:** Protocolos de comunicação industrial e IoT para disponibilização dos dados de forma segura na nuvem.
*   **Frontend (Interface Web):** Dashboards interativos para operação em tempo real com baixa latência.
